# Politique de sécurité

Ce dépôt est un **profil GitHub** : il ne contient pas de code exécutable, mais uniquement la
présentation (README) et d'éventuels fichiers de configuration de communauté (`.github/`,
`SECURITY.md`, `FUNDING.yml`).

## Versions prises en charge

| Version | Prise en charge |
|---------|-----------------|
| `main` (contenu du profil) | ✅ |

## Signaler une vulnérabilité

**Ne publiez pas** d'issue publique pour signaler un problème de sécurité.

Si vous repérez un contenu sensible (clé, secret, donnée personnelle) ou une faille dans les
fichiers de ce dépôt :

1. Ouvrez une **[GitHub Security Advisory](https://github.com/nickdesi/nickdesi/security/advisories/new)**
   privée sur ce dépôt pour que le signalement reste confidentiel pendant le tri.
2. Décrivez le fichier concerné, l'impact et, si possible, une correction suggérée.

Nous visons un accusé de réception sous **72 heures**.

## Bonnes pratiques

- N'incluez jamais de secrets, clés API ou données personnelles dans une PR vers ce dépôt.
- Signalez tout dépôt lié (FFBB MCP, Gerzat Live, unbound-adguard-installer…) à son propre mainteneur.
